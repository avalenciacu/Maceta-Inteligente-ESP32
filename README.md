# Maceta Inteligente ESP32

Proyecto final de Diseño Electrónico: Maceta inteligente interactiva basada en ESP32.

## Descripción
Sistema autónomo que comunica las necesidades de una planta mediante expresiones faciales en una pantalla GC9A01, medición de humedad del suelo y temperatura ambiental, e interacción táctil capacitiva. No incluye riego automático ni requiere internet.

## Componentes previstos
- ESP32-WROOM-32
- Pantalla GC9A01 (240 × 240)
- Sensor de humedad FC-28
- Sensor de temperatura DS18B20
- Electrodo táctil capacitivo
